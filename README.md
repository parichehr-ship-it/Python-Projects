# Python Projects 🐍

Welcome to my Python Projects repository! This is a collection of hands-on projects and exercises I have built while learning Python and completing the **"100 Days of Code: The Complete Python Pro Bootcamp"** challenge.

## 📂 Projects Included
Here is a list of the projects currently available in this repository:

*   **Tip Calculator:** A simple program to calculate the tip and split the bill among friends.
*   **Treasure Island:** A text-based adventure game where choices determine the outcome.
*   **Rock, Paper, Scissors:** The classic hand game played against the computer.
*   **Password Generator:** A tool that generates strong, randomized passwords based on user preferences.
*   **Hangman Game:** A classic word-guessing game with ASCII art visuals.
*   **Caesar Cipher:** A program to encrypt and decrypt messages using the Caesar cipher technique.
*   **Blind Auction:** A silent auction program to determine the highest bidder.
*   **Blackjack:** A command-line version of the classic card game.
*   **Number Guessing Game:** A fun game where the user tries to guess a randomly generated number within a certain range.

## 🛠️ Skills & Concepts Applied
Throughout these projects, I have practiced and applied the following Python concepts:
*   Core Python syntax (Variables, Data Types, Strings)
*   Data Structures (Lists, Dictionaries, Tuples)
*   Control Flow (`if/elif/else` statements)
*   Loops (`for` and `while` loops)
*   Functions, Parameters, and Scope
*   Importing and utilizing Python modules (e.g., `random`)
